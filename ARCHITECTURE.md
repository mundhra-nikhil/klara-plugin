# Klara Plugin Architecture

## Overview
The Klara Word add-in is a React-based frontend (`SuggestionsTab.tsx`) integrated with the Office.js API (`word-context.ts`). It connects to a Python backend to execute AI-driven jobs.

## Components
1. **Frontend**: React, Webpack, Office.js
2. **Backend**: Python, FastAPI
3. **AI Pipeline**: Structural formatting fixes and JSON template engine.
